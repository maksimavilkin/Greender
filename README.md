# ЗавоЗелёные

Это сайт, на котором можно находить экологические мероприятия, создавать свои заявки и откликаться на чужие.

## Как устроена база

Для хранения данных используется SQLite. База создаётся автоматически при первом запуске сервера.

В базе есть таблицы:
- `users` - пользователи, их имена, контакты и пароли в защищённом виде.
- `events` - мероприятия, их названия, описания, места, города и районы.
- `responses` - отклики пользователей на мероприятия.
- `password_resets` - данные для восстановления пароля.
- `app_migrations` - отметки о выполненных обновлениях базы.

Таблицы связаны по номерам записей. В `events` поле `creator_id` указывает на автора мероприятия. В `responses` поля `user_id` и `event_id` указывают, кто откликнулся и на какое мероприятие.

## Как запустить

1. Установить Node.js (версия 18 или новее).
2. Открыть папку проекта в терминале.
3. Ввести `npm install`.
4. Ввести `npm start`.
5. Открыть в браузере `http://localhost:3000`.

После запуска сервер сам создаст файл `zavozelenye.db`. При следующем запуске данные из него останутся на месте. Файл базы не нужно удалять.

## Примеры запросов

Получить список мероприятий:

```http
GET http://localhost:3000/api/events
```

Зарегистрировать пользователя (в Postman выбрать POST, Body -> raw -> JSON):

```http
POST http://localhost:3000/api/register
```

```json
{
  "name": "Иван",
  "surname": "Иванов",
  "contact": "ivan-test@example.com",
  "password": "testpass123"
}
```

Посмотреть свои данные после входа:

```http
GET http://localhost:3000/api/me
```

Для последнего запроса нужен заголовок `Authorization: Bearer ТОКЕН`, где токен выдаётся после входа или регистрации.

## Как проверить работу

В Postman можно отправить запрос на получение мероприятий, зарегистрировать пользователя и создать новое мероприятие. Затем перезапустить сервер и ещё раз получить список. Созданная запись должна остаться.

В коде сервера также есть операции с несколькими изменениями базы. Если возникает ошибка, изменения отменяются через `ROLLBACK`.

Для проверки скорости поиска можно сравнить одинаковый запрос до и после создания индекса в SQLite. На маленькой базе разница может быть почти незаметной.
